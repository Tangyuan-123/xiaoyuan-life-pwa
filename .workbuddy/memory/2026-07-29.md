## 推送到 GitHub + 开 Pages（手机访问方案）
- **沙箱网络限制**：`git push` 走 `https://github.com/...` 被拦截（Connection reset / timeout），但 `https://api.github.com` 可通（200）。所以改用 **GitHub REST API（Git Data API）** 推送：写 Node 脚本 `sync_github.js`（在 node workspace）按顺序做 GET ref→GET commit→GET tree(recursive)→逐文件 POST blobs→POST trees(base_tree)→POST commits→PATCH refs/heads/main；并 POST /repos/.../pages 开 Pages。脚本用 `git ls-files > .tracked.tmp` 取文件清单，推完删掉。
- 用一次性 Token `ghp_ahalc...` 成功推送（PUSH status 200），Pages 已启用：`https://tangyuan-123.github.io/xiaoyuan-life-pwa/`。注意 Pages 私有仓库在免费账号可能对外 404，需公开仓库或 GitHub Pro 才能公网访问；仓库代码不含用户数据（数据在 localStorage/IndexedDB），公开仅暴露代码。
- 沙箱里 curl Pages 域名报 schannel 吊销离线错误(CRYPT_E_REVOCATION_OFFLINE)，属沙箱证书检查问题，不影响手机浏览器访问。
